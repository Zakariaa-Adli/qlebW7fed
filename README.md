# 🃏 qlebW7fed

**qlebW7fed** (*Moroccan Darija for "Flip & Memorize"*) is a modern, interactive flashcard web application built to streamline active recall and make studying fast, engaging, and effective.

## 🌐 Live Demo
[View Live Project](https://qlebw7fed.vercel.app) *(Replace this URL with your actual deployed link)*

## ✨ Features
- **3D Card Flip Animation:** Smooth flip transitions to reveal answers on click or keyboard press.
- **Full CRUD Management:** Create, edit, and delete custom flashcards effortlessly.
- **Persistent Storage:** Automatically saves your cards in `localStorage` so your progress is never lost.
- **Progress Tracking & Shuffle:** Mark cards as mastered, track your study progress, and shuffle decks for better retention.
- **Responsive Design:** Clean interface optimized for both desktop and mobile screens.
